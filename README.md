# Personal Portfolio

Welcome to my personal portfolio! This website showcases my background, technical skills, projects, and learning journey as a Computer Science Engineering student.

## 🌐 About the Project

This portfolio website is designed to introduce me, highlight the technologies I work with, showcase my projects, and provide a way for people to connect with me.

It features a clean, modern, and responsive design with separate sections for my introduction, skills, projects, learning journey, and contact information.

## ✨ Features

- **Home:** Introduction and overview of my profile.
- **About Me:** Information about my background and interests.
- **Skills:** Showcases my programming languages and technical skills.
- **Projects:** Displays some of my academic and personal projects.
- **Learning Journey:** Highlights my current learning goals and future plans.
- **Contact:** Provides contact information and a message form.
- **Responsive Design:** Designed to provide a smooth browsing experience across different screen sizes.
- **Back to Top:** Allows users to quickly return to the top of the page.

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd Portfolio
   ```

3. Open `index.html` in your browser.

You can also open the folder in Visual Studio Code and use the Live Server extension to run the website.
